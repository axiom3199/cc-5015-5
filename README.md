# 服装 UV 展开工作台 — 多纹理分区与图岛接缝优化

在原有 LSCM 展开、像素密度打包、畸变/翻转/重叠检查之上，本轮交付：

1. **多纹理分区布局（显式编号纹理格）**
2. **图岛接缝优化内核（拉伸 + 共享边误差驱动）**
3. **模型操作视窗联动（点选接缝、优化、展开后三维/二维同步更新）**

## 运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
# 浏览器打开 http://127.0.0.1:8000/
```

测试：

```bash
.venv/bin/python -m pytest tests/ -q
```

## 界面怎样启动各项能力

所有功能都在浏览器页面内，不需要单独跑脚本。

### 1. 接缝与展开（三维视窗）
- 顶部下拉选择测试网格（含「镜像双图岛」「细长弧形衣片」），点「载入测试网格」，或上传 OBJ。
- 三维视窗点棱边切换接缝（红色）；「最短路径」模式下点两个顶点自动沿最短边布缝。
- 点 **优化接缝**：由 `app/seams_opt.py` 内核按角度/面积拉伸与共享边误差做贪心迭代，
  成功后自动重展，三维模型与二维图表同时刷新；失败（如非流形）原因直接回显到侧栏警告。
- 勾选 **三维棋盘预览**：把展开后的 UV 棋盘贴回三维模型，直观查看拉伸。

### 2. 多纹理分区（右侧「纹理格布局」面板）
- 勾选「启用显式编号纹理格」，用「新增纹理格」建立带唯一编号（如 1001、1002）的格，
  每格独立设置纹理分辨率、边距、采样余量和绑定的纹理资源键。
- 「允许图表跨格」控制项目策略：**禁止时**超大图表整片保留并在「布局无解原因」中报告，
  绝不切断未选择的接缝，也不靠逐格缩放掩盖。
- 点「应用格布局并重展」。二维视图按编号画格，图表标签显示所在格号与锁定标记。

### 3. 锁定与格号映射（「图表锁定与格号映射」面板）
- 每个图表可设为「锁定布局」、指定格号、是否允许 90° 旋转（默认禁止）。
- 锁定后点「仅重排未锁定图表」：锁定图表保持原像素位置，其余重新布局。
- 锁定与当前像素密度冲突时，给出具体原因（占用像素、格可用区域、纹理尺寸/边距/余量）。

### 4. 导出与重开
- 「资产导出」提供 OBJ（含 UV 与 `tile_id=`/`chart=` 格号映射注释）、棋盘 PNG、畸变报告 JSON。
- 项目按网格**拓扑指纹**持久化：重新上传同拓扑模型即可恢复接缝、纹理格、锁定约束与实际布局；
  版本快照保存/恢复整套状态。导出是可用资产坐标，不是二维截图。

## 关键设计约束（对应验收点）

- 全局像素密度对所有图表一致；布局只平移/按需 90° 旋转，**不做逐图表缩放**。
- 同一几何尺寸的图表落到不同分辨率纹理格时，像素足迹相同（UV 占比按各格分辨率换算）。
- 纹理格编号必须唯一；纹理资源键不可重复绑定；相近格号绑定不同资源会给出提示，
  绑定到纹理清单之外的资源直接报错。
- 单格工程（未启用多格）走原有 `pack_charts` 路径，UV 行为与旧版完全一致。
